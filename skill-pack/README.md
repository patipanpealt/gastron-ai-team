# Skill pack: pixel-art-2d-office

How to install for another AI:
- Claude Code: copy the folder `pixel-art-2d-office/` into `~/.claude/skills/` (user-wide) or `<project>/.claude/skills/`.
- Other agents: give them `pixel-art-2d-office/SKILL.md` first, then the files in `references/`; the generator scripts in `scripts/` run with Python 3 + Pillow + numpy (run from a copy of `pixel-art/sprites/`).
